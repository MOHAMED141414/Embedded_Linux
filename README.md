## 📚 Topics Covered

### C++ (`02c++/`)
- Modern C++ (C++11/14/17) features
- Object-Oriented Programming — classes, inheritance, polymorphism
- Templates and STL (vectors, maps, algorithms)
- Memory management (smart pointers, RAII)
- File I/O and streams

### Python (`Tasks/01Python/`)
- Python scripting for Linux automation
- File system operations
- Process management
- Basic networking scripts
- Data parsing and manipulation

## 🚀 Getting Started

```bash
git clone https://github.com/MOHAMED141414/Embedded_Linux.git
cd Embedded_Linux

# Build C++ tasks
cd 02c++
g++ -std=c++17 -o output main.cpp

# Run Python tasks
cd Tasks/01Python
python3 script.py
```
